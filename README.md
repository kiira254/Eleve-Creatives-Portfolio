THEME

PAGES
- index.html — Home and portfolio overview
- teaching.html — Teaching & ICT Training
- digital-marketing.html — Digital Marketing
- graphic-design.html — Graphic Design

HOW TO VIEW
1. Extract the ZIP file.
2. Keep all HTML files, style.css and the assets folder together.
3. Open index.html in a web browser.
4. Use the top navigation to move between the three separate portfolio pages.
